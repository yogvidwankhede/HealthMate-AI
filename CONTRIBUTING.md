# Contributing

This is a small research and teaching project. Bug reports, documentation fixes and reproducibility
fixes are welcome. Please open an issue first for anything larger than a small fix.

- Do **not** add copyrighted text (for example extracts of medical encyclopedias) or model outputs
  containing patient data to the repository.
- Keep changes small and include how you checked them. Run the tests in `paper/` if you touch evaluation code.
- This project gives no medical advice and must not be presented as doing so.
- If you used an AI assistant to write a contribution, say so in the pull request.
